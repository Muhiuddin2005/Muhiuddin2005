### 🙋‍♂️ About Me

- 🔹 **Advanced Frontend & State:** Building dynamic applications with Next.js and React, using TanStack React Query for seamless data fetching and caching.
- 🔹 **Component Systems & Styling:** Architecting sleek, responsive user interfaces with Shadcn UI, Tailwind CSS, and Vanilla CSS, enhanced by Framer Motion for micro-animations.
- 🔹 **Backend Architecture & Security:** Writing scalable server-side code with Node.js, Express.js, and TypeScript, secured by JSON Web Tokens (JWT), bcryptjs hashing, and strict Zod schema validation.
- 🔹 **Databases & ORMs:** Managing data efficiently across both relational and non-relational systems using PostgreSQL (Neon DB), MongoDB, and Prisma ORM.
- 🔹 **Real-Time, Cloud & Payment Integrations:** Implementing real-time communication via Socket.io, processing secure financial checkouts via Stripe, handling media streams through Multer and the Cloudinary API, and setting up automated email delivery with Nodemailer and EJS templates.
- 🔹 **Polished UX Infrastructure:** Utilizing Axios with custom interceptors for automatic token management, Recharts for data visuals, and SweetAlert2 and Sonner for clean user alert toasts.
